VulnHubEasy● Rooted

Full chain from external recon to shell: Nmap surfaced FTP / SSH / HTTP, directory brute-forcing uncovered a hidden WordPress install, and weak admin credentials led to a reverse shell as www-data. Escalated by cracking a user hash offline and pivoting over SSH.

Key takeawayDocumented two parallel attack paths (service vs. web) and the quirk that a theme's 404.php only fires when requested directly.

VulnHubMedium● Rooted

Directory enumeration exposed an /openemr path running an outdated OpenEMR v4.1.0 EHR. Version fingerprinting let me match a known public CVE, extract credentials, and crack the recovered hashes for admin access.

Key takeawayPrecise version identification turns a blind attack into a targeted one — fingerprint first, then find the exact matching exploit.
